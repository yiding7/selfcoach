# 知识库（私有资料区）

放你自己的专业资料：减脂指导、营养学教材、教练课程笔记、动作讲解、论文摘录。

**这个目录的内容不进版本库**，只有你本机有。仓库里只保留这份 README 和目录结构，
所以别人 clone 下来会得到一个空的、可以填自己资料的架子。

---

## 目录约定

```
knowledge/library/
  INDEX.md          ← 你维护的总目录（助手先读这个）
  nutrition/        营养、饮食结构、食物选择
  training/         训练方法、动作、周期化
  cardio/           有氧、心率、能量系统
  recovery/         睡眠、疲劳管理
  reference/        原始资料：PDF、电子书、课程讲义、论文
  notes/            你自己的读书笔记和摘录
```

目录不是强制的，按你顺手的来。只有一条是重要的：**维护 `INDEX.md`。**

## 为什么 INDEX.md 是关键

助手不会把整个目录读一遍 —— PDF 很大，全读会挤掉真正要紧的上下文。
它的实际流程是：

1. 先读 `INDEX.md`，看有哪些资料、各自讲什么
2. 判断当前问题跟哪一份相关
3. 只打开那一份

所以 `INDEX.md` 里每条写清楚**这份资料能回答什么问题**，比写标题有用得多。

### INDEX.md 的格式

```markdown
# 知识库总目录

## 营养
- `nutrition/蛋白质摄入指南.md` —— 不同训练量下的蛋白需求、分配时机、
  植物蛋白折算。回答「我该吃多少蛋白」「练后必须马上补吗」。
- `reference/减脂营养学-第3版.pdf` —— 教材，第 4 章讲能量缺口设定，
  第 7 章讲平台期。较长，建议按章节定位。

## 训练
- `training/新手周期化.md` —— 线性递进什么时候失效、怎么转双因子。
```

## 支持的文件格式

| 格式 | 助手能不能读 | 建议 |
|---|---|---|
| `.md` `.txt` | ✅ 直接读 | **最推荐**，检索和引用都最准 |
| `.pdf` | ✅ 能读，按页 | 大文件在 INDEX 里标好章节页码 |
| `.docx` `.epub` | ⚠️ 不一定 | 建议先转成 md |
| `.jpg` `.png` `.heic` | ✅ 能看图 | 讲义拍照可以，但不如文字好检索 |

扫描版 PDF（图片型、没有文字层）检索效果差很多。有原文的话优先放原文。

## 优先级：这些资料**不能**推翻的三件事

助手在用这里的资料时，遵守这个顺序：

```
安全边界  >  你的个人档案  >  这里的知识库  >  模型自己的通用知识
```

具体说：

1. **`knowledge/safety-boundaries.md` 永远最高。**
   知识库里如果有「怎么调整某某药物剂量」「用某某补剂改善某项指标」这类内容，
   助手不会照搬 —— 用药和诊断一律转给医生。资料再权威也不例外。
2. **`profile/health-constraints.md` 次之。**
   知识库里推荐的动作，只要命中你记在那份文件里的禁忌，都会被挡下来。
3. **知识库高于模型的通用知识。**
   这是它存在的意义：你信任的资料优先于模型的泛泛之谈。有冲突时助手会
   明确说「按你知识库里的 X 说法」，而不是悄悄换掉。

放进来的资料如果和上面两条冲突，助手会**指出冲突**，而不是默默选一边。

## 加了资料之后

不需要跑任何命令，没有索引要重建。下次对话直接说：

> 我在知识库里加了一份讲蛋白质摄入的资料，之后聊饮食的时候参考一下。

或者让助手自己看：

> 看一下 knowledge/library/INDEX.md，然后按里面的方法评估我现在的饮食。
