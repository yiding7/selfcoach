# 围度测量规程

> 通用方法，任何人都能用。**不含任何个人数据** —— 具体数值在 `data/body/`，
> 个人的测量习惯和目标值在 `profile/personal-context.md`。
>
> 这份文件解决一个问题：**围度数据的价值几乎全部来自「条件一致」，而不是「测得准」。**
> 一个每次都偏大 1.5 cm 但方法固定的人，能测出可用的趋势；
> 一个每次都很认真但位置和松紧不固定的人，测出来的是噪声。

## 一、通用原则

### 1. 同条件

| 条件 | 要求 | 为什么 |
|---|---|---|
| 时间 | 早上起床后 | 一天中腹围最小、最稳定；晚上受进食和体位影响 |
| 排空 | 排尿后 | 膀胱充盈可影响腰围读数 |
| 空腹 | 进食饮水前 | 胃内容物直接影响腰围 |
| 着装 | 尽量少，直接贴皮 | 隔着衣物读数不可比 |
| 姿势 | 自然站立，双脚与肩同宽，双臂自然下垂 | 收腹、挺胸、扭身都会改变读数 |

### 2. 同工具

用**软尺**（布尺或纤维尺），不要用钢卷尺。理想的是带**恒定张力扣**的体围尺
（拉到固定力度会「咔」一声），几十块钱，能消掉最大的一个误差源。

### 3. 同手法

- 软尺**贴皮但不勒进肉里** —— 判据：尺子能贴合皮肤，但松开手指后不会自己滑落
- 保持软尺**水平**（绕体一周在同一高度）。自己量时对着镜子看背面是不是也水平
- **正常呼气末读数** —— 不是深吸气，也不是用力呼尽
- 同一个位置量两次，差值 > 0.5 cm 就量第三次取中位数

### 4. 同测量者

不同的人手劲和位置判断不一样，能差 1–3 cm。

> **自测优先。** 自己量的绝对值未必最准，但同一个人的手法最稳定，趋势才成立。
> 记录里要标清 `source`，**不同来源的读数不能放在同一条趋势线上逐点比较** ——
> 只能当量级参考。换测量者相当于换了把尺，序列要重新起算。

## 二、各围度的测量位置

| 项目 | `type` | 位置与手法 |
|---|---|---|
| **腰围** | `weist` ⚠️ | **脐水平**绕体一周，水平。正常呼气末读数。不收腹 |
| **颈围** | `neck` | 喉结**下方**最细处，软尺水平（不要顺着下颌斜上去）。这是量领围时最常出错的地方 —— 裁缝量的「领围」通常故意放松 2–4 cm，和体围不是一个数 |
| **胸围** | `chest` | 乳头水平绕体一周，手臂自然下垂，正常呼气末 |
| **上身最窄处** | `torso_narrowest` | 肋骨下缘与髂嵴之间的自然最细处，通常在脐上 2–5 cm |
| **臀围** | `bot` ⚠️ | **臀部最丰满处**绕体一周，水平。双脚并拢 |
| **胯围** | `hip` | 髂嵴（骨盆最宽的骨点）水平，比臀围高，通常也更小。和臀围是两个数，别混 |
| **上臂围** | `upper_arm` | 上臂最粗处（肱二头肌肌腹）。**自然放松下垂**，不发力、不屈肘 —— 要量发力围度就单独记，别和放松值混 |
| **手腕围** | `wrist` | 腕骨最细处，桡骨茎突远端。基本不随体重变化，可以当**骨架参考**和尺子的校验值 |
| **大腿围** | `thigh` | 大腿最粗处（通常在臀褶下 2–5 cm），水平。双脚与肩同宽、重心均匀 |
| **膝围** | `knee` | 髌骨中点水平，腿伸直放松 |
| **小腿围** | `calf` | 小腿最粗处（腓肠肌肌腹），站立、重心均匀 |
| **头围** | `head` | 眉弓上方与枕骨最突处绕一周。成年后基本不变，仅作档案 |

> ⚠️ **`weist`（腰围）和 `bot`（臀围）是训记接口的历史拼写，不要「修正」成
> `waist` / `hip` —— 改了写回时字段对不上。** 新增的围度类型用上表的英文名。

**只量得动三个的话**：腰围、颈围、大腿围。腰围是脂肪信号，颈围配腰围能算体脂估算，
大腿围是下肢肌肉信号。

## 三、由围度推出的两个指标

### 1. 腰高比 WHtR

```
WHtR = 腰围 / 身高          （同单位）
```

| WHtR | 含义 |
|---|---|
| ≥ 0.6 | 高风险 |
| 0.5 – 0.6 | 偏高 |
| **< 0.5** | 常用的健康阈值 |
| ~0.45 | 运动员区间 |

优点是不需要任何其他数据，且**「腰围 < 半个身高」这条经验法则跨人种通用**。

### 2. Navy 体脂估算

只要腰围、颈围、身高三个数（男性）：

```
体脂% = 86.010 × log10(腰围 − 颈围) − 70.041 × log10(身高) + 36.76
        ——  三个数都用**英寸**（cm ÷ 2.54）
```

女性还需要臀围：

```
体脂% = 163.205 × log10(腰围 + 臀围 − 颈围) − 97.684 × log10(身高) − 78.387
```

**怎么用它，比它准不准更重要：**

- 它的**绝对值有 ±3–4 个百分点的误差**，不要拿去和别人比、也不要当体检结论
- 但**同一个人、同一套手法下的变化方向是可靠的** —— 这才是它的用途
- 男性公式里颈围基本不变，所以**它本质上是腰围的一个换算**，不是独立信息。
  价值在于能把腰围翻译成「体脂 %」这种更容易对话的单位
- **对颈围敏感**：颈围差 1 cm，体脂估算差约 0.7 个百分点。
  所以颈围一旦换了测量者或手法，整条估算序列都要重新起算

### 参考：视觉表现对应的体脂区间（男性，很粗略）

| 体脂 | 大致表现 |
|---|---|
| 20%+ | 腹部有明显软组织堆积 |
| 18% | 腹肌线条**隐约可见**，光线好时上腹能看出轮廓 |
| 15% | 上四块比较清楚 |
| 12% | 六块可见 |
| 10% 以下 | 需要严格控制，不适合作为长期维持目标 |

个体差异很大（脂肪分布、皮肤厚度、肌肉量都会影响），**这张表只用来把一个视觉目标
翻译成一个大致的腰围工作值，不是判据**。视觉目标的判据永远是本人照镜子。

## 四、频率与记录

| 项目 | 建议频率 | 理由 |
|---|---|---|
| 体重 | 每天 | 单日噪声大（可达 ±1.5 kg），必须靠密集采样出 7 日均线 |
| 腰围 | 每周 1 次，固定星期几 | 变化慢，加密采样只会引入噪声；固定星期几能对齐周内饮食节律 |
| 其他围度 | 每 4–8 周 | 变化更慢 |
| 固定条件照片 | 每 1–4 周 | 唯一直接测「视觉目标」的手段 |

日期必须有。**`source`（谁测的）是参考字段，不强制** —— 但换人、换尺、换手法这几种
情况值得补一句，否则半年后没人分得清一次 2 cm 的跳变是真的瘦了还是换了把尺。
来源不明的读数不作废，只是别拿去和自测序列逐点比。

## 五、常见误差源

| 误差源 | 量级 | 对策 |
|---|---|---|
| 软尺松紧不一致 | ±1–2 cm | 恒定张力尺；或固定「贴皮不勒」的判据 |
| 位置偏移（腰围尤其） | ±2–3 cm | 认准脐水平；对镜确认水平 |
| 呼吸时相 | ±1–2 cm | 一律正常呼气末 |
| 收腹 | ±2–4 cm | 放松，别照镜子的时候下意识收 |
| 换测量者 | ±1–3 cm | 序列重新起算，别逐点比 |
| 进食 / 时间 | ±1–2 cm | 晨起空腹排尿后 |
| 裁缝的「领围/腰围」 | 比体围大 2–4 cm | **不要和自测值混用** |

误差加起来能到 5 cm 以上 —— 比大多数人半年的真实变化还大。
**这就是为什么规程比精度重要。**
