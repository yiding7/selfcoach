# 训练分析

## 命令

```bash
./scripts/hc summary --date 2026-07-30      # 单次训练的详细指标
./scripts/hc compare --date 2026-07-30      # 全部四个视角（不带 --date 用最近一次）
./scripts/hc compare --group 背              # 只看某个部位
./scripts/hc next 背                         # 下次这个部位的具体建议
```

## 四个视角，各自回答不同的问题

每次训练的选材都在变 —— 这次全做划船，下次全做下拉，再下次做宽距+窄距+反握三种下拉。
所以工具不只做「本次 vs 上次同部位」这一种对比。

### 1. 逐动作纵向 ← **最可靠，优先讲这个**

每个动作和**它自己**上一次做的时候比，在**全部历史**里找，不限于上一次同部位训练。

所以「宽距高位下拉」哪怕隔了三次训练才再做，也能干净地比出进步。
这一层完全不受选材变化影响，是判断「有没有变强」最可信的依据。

### 2. 发力模式

垂直拉 / 水平拉 / 上斜推 / 髋铰链 / 膝主导 …… 这类分类。

宽距、窄距、反握高位下拉都是「垂直拉」。所以两次训练动作零重合时，
模式层依然能比出容量和组数的变化。

### 3. 肌群滚动窗口

最近 28 天 vs 前 28 天。单次训练波动太大，趋势要靠窗口看。

### 4. 结构平衡 ← **最有价值，普通健身 App 给不出**

看**过去 28 天**每个部位内部各模式的比例：

- 背：垂直拉 vs 水平拉（宽度 vs 厚度）
- 胸：上斜推占推类的比例（上胸最容易练漏）
- 肩：有没有练后束（几乎不参与推举，必须单独练）
- 腿：膝主导 vs 髋铰链（股四 vs 后链）
- 三头：有没有过头伸展（长头需要拉长位）

**只看滚动窗口，不看单次。**单次训练有侧重完全正常，甚至是好事（专项化）；
值得提示的是持续几周的结构性缺失。

## 置信度 —— 这是最要紧的一条

每个对比都带置信度，**结论按置信度门控**：

| 置信度 | 含义 | 能比什么 |
|---|---|---|
| `exact` | 同一个动作名 | 重量、次数、1RM 都能直接比 |
| `variant` | 同族不同握法/版本 | 重量大致可比，**必须说明握法变了** |
| `pattern` | 同模式不同动作 | 只能比组数和容量，**重量绝对不能比** |
| `group` | 只是同一个部位 | 只能比组数和频率 |
| `none` | 数据不足 | 什么都不比 |

**低于门槛时，工具会明说「暂时不可比」。你要照着说，不要自己补一个对比出来。**

具体地：
- 看到「两次没有共同动作，负荷不可比」→ 不要自己去比重量。
  器械推胸 40kg 和俯卧撑折算的 51kg 不是一回事，硬比会得出「力量下降 20%」
  这种既错误又打击人的结论。
- 看到「本地历史里第一次做」→ 说新动作前两次先摸重量，别急着冲。
- 看到「同族变体」→ 一定要提一句上次做的是哪个变体。

宁可少说一条，也不要说一条错的。用户明确要求过这一点。

## 技术点，用户可能会问

**估算 1RM**：Epley 公式 `w × (1 + 次数/30)`，是**估算**不是实测，超过 12 次会标低置信度。
永远带上「估算」两个字。注意顶组重量最大 ≠ 估算 1RM 最大：
60kg×10 的 e1RM（80）比 65kg×8（约 78）更高。

**自重与辅助**：自重动作按体重×系数折算。辅助器械（引体辅助等）记录的是
**助力配重，越大越省力**，所以变强的方向是把配重**往下调**，不要说成「加重」。

**RPE 覆盖率为 0**：用户目前不记 RPE，所有依赖主观强度的判断都不会输出。
**不要自己编一个强度评价。** 也不用反复劝他记 —— 提过一次就够了。

**参考区间**：MEV/MAV/MRV 是人群统计值，不是处方，减脂期的可恢复上限还更低。
只用来提示「可能偏少/偏多」，用户自己的感受优先。

## 处方护栏

`hc next` 会输出生效的护栏代码，要解释为什么：

- `DEFICIT_HOLD` —— 体重周降幅超 1%，处在明显缺口期。这个阶段**力量维持住就是成功**，
  所以不追加重量。这条要好好说，别让用户觉得没加重就是没进步。
- `OVER_MRV_HOLD` —— 本周该部位已超可恢复上限。
- `UNDER_MEV` —— 低于最小有效容量，可以加 2 组。

## 数据不足时

少于 3 次可比训练时，工具只出 `INSUFFICIENT_DATA` / `NO_ANCHOR`，不出评价。
这是对的 —— **不要**自己补一个评价上去。诚实地说「再练一次同部位就能给你对比了」。
