# 训练分析

## 命令

```bash
./scripts/hc summary --date 2026-07-12          # 单次训练的详细指标
./scripts/hc compare --date 2026-07-12          # 本次 vs 上次同部位（不带 --date 用最近一次）
./scripts/hc compare --group 胸                  # 只看某个部位
./scripts/hc next 胸                             # 下次胸日的具体建议
```

## 输出怎么读

`hc compare` 会对本次训练涉及的**每个肌群**分别做对比，因为一次训练里
通常混着好几个部位（比如胸日里混了三头）。整次训练笼统地比是没意义的。

结论分四类，直接对应用户想听的：

- **优点** —— 有数字支撑的进步
- **缺点** —— 可以更好的地方
- **改进点** —— 每条缺点对应的具体下一步
- **信息** —— 数据本身的说明

工具保证：每条缺点都挂着改进点，每条优点都有数字。你照着讲就行。

## 几个必须讲清楚的技术点

用户可能会困惑，主动解释：

### 「两次没有共同动作，负荷不可比」

出现这句话时，**不要**自己去比重量。器械推胸的 40kg 和俯卧撑折算的 51kg
不是一回事，硬比会得出「力量下降 20%」这种既错误又打击人的结论。

正确的讲法：这次动作换了一批，所以只比总容量和组数这种可加总的量。
想看力量进展，建议每次保留 1~2 个相同的主项动作。

### 估算 1RM

用 Epley 公式 `w × (1 + 次数/30)` 算的，是**估算**不是实测。
超过 12 次的组会标注低置信度。永远带上「估算」两个字。

### RPE 覆盖率为 0

用户没记 RPE 时，所有依赖主观强度的判断都不会输出。
不要因此编一个强度评价出来。可以温和地提一句：
只记每个动作**最后一组**的 RPE 就够，一次训练多花不到一分钟。

### 自重与辅助动作

- 自重动作按体重×系数折算，标注「估算」
- 辅助器械（引体辅助等）记录的是**助力配重，越大越省力**，
  所以变强的方向是把配重**往下调**，不要说成「加重」

### 参考区间

MEV/MAV/MRV 是人群统计值，不是处方。而且减脂期的可恢复上限会更低。
只用来提示「可能偏少/偏多」，用户自己的感受优先。

## 处方护栏

`hc next` 会输出生效的护栏代码，要向用户解释为什么：

- `DEFICIT_HOLD` —— 体重每周降幅超过 1%，处在明显缺口期。
  这个阶段**力量维持住就是成功**，所以不追加重量。这条要好好说，
  别让用户觉得没加重就是没进步。
- `OVER_MRV_HOLD` —— 本周该部位已超过可恢复上限，先别加。
- `UNDER_MEV` —— 低于最小有效容量，可以加 2 组。

## 数据不足时

少于 3 次可比训练时，工具只出 `INSUFFICIENT_DATA` / `NO_ANCHOR`，
不出评价。这是对的 —— **不要**自己补一个评价上去。
诚实地说「再练一次同部位就能给你对比了」。
